# 🛡️ SafeHer AI

SafeHer AI is an AI-powered personal safety assistant designed to provide quick safety support during emergency situations.

## 🚀 Features

- 🚨 SOS Emergency System
- 👥 Emergency Contact Management
- 📍 Location Detection and Safety Map
- 🤖 AI Safety Assistant
- 🎙️ Voice SOS Detection
- 🧠 ML-Based Safety Risk Prediction
- 📱 Free SMS Launcher
- 📞 Free Phone Call Launcher
- 🔐 User Login and Registration
- 💾 SQLite Database
- 📜 SOS Alert History

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- SQLAlchemy
- Gemini AI
- Machine Learning
- Folium
- Geopy
- Speech Recognition
- pyttsx3
